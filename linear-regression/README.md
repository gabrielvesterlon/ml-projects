# 📐 House Price Predictor with Linear Regression

A study project that uses **Linear Regression** to predict house prices based on area, number of bedrooms and age. It shows two of the model's biggest strengths: it is **interpretable** (you can read the formula it learned) and it can **extrapolate** beyond the training range.

![Results](linear_regression_results.png)

## 🧠 What it does
- Generates a synthetic dataset of 300 houses using a hidden pricing rule:
  `price = 100,000 + 3,500 × area + 30,000 × bedrooms − 4,000 × age + noise`
- Adds Gaussian noise (std of R$ 30,000) to simulate factors the data doesn't capture
- Trains a `LinearRegression` and evaluates it with 5-fold cross-validation and a held-out test set (R², MAE and RMSE)
- Prints the formula learned by the model and compares it with the hidden rule
- Checks the residuals to make sure the errors have no pattern
- Compares Linear Regression and XGBoost on a house **outside** the training range

## ▶️ How to run
From the root of the repository:
```bash
pip install -r requirements.txt
python linear-regression/house_price_linear_regression.py
```

## 📊 Results
| Metric | Value |
|--------|-------|
| Cross-validation R² | 0.980 (± 0.005) |
| Test R² | 0.973 |
| MAE | R$ 25,397 |
| RMSE | R$ 32,324 |
| MAE of the lazy baseline (always the mean) | R$ 168,282 |
| Best possible RMSE (noise level) | ~R$ 30,000 |

**Formula learned by the model:**
```
price = 93,426 + 3,581 × area_m2 + 29,475 × bedrooms − 4,405 × house_age
```
Very close to the hidden rule (100,000 / 3,500 / 30,000 / −4,000).

**Extrapolation test** (400 m², 4 bedrooms, 5 years old; the largest house in training had 250 m²):

| | Price |
|--|--|
| True price (hidden rule) | R$ 1,600,000 |
| Linear Regression | R$ 1,621,869 |
| XGBoost | R$ 1,076,510 |

## 💡 Key takeaways
- **Interpretability:** each coefficient has a clear meaning, e.g. "each extra m² adds about R$ 3,581 to the price". Tree-based models can't be read this way.
- **Extrapolation:** Linear Regression keeps following the trend beyond the data it has seen, while XGBoost stays stuck at the highest price it saw in training (the flat blue line in the plot), missing by more than R$ 500k.
- **Healthy residuals:** the errors are scattered randomly around zero, which means the straight-line assumption fits this data well.
- **Close to the ceiling:** the RMSE of ~R$ 32k is close to the R$ 30k of random noise, which no model can predict.

## ⚠️ Limitations
- The data was generated by a linear rule, so it is the ideal scenario for this model. Real house prices have non-linear effects (location, interactions between features), where Linear Regression can struggle.
- Extrapolation is only safe while the linear trend still holds in the real world.
